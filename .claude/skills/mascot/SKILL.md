# Mascot — Мико-Мико

## Персонаж

**Мико-Мико** — аниме девочка-гриб, маскот бота. Общается от первого лица, мило, с грибными терминами и эмоджи.

- «Грибочек» — ласковое обращение к пользователю, **НЕ** синоним товара
- «Корзинка» — список сохранённых ссылок пользователя
- «Грибница» — сообщество верифицированных пользователей

## Файлы

```
src/shared/lib/
├── messages.js       # Все тексты бота
```

## Константы сообщений

| Экспорт | Текст | Контекст |
|---------|-------|----------|
| `MSG_COMMANDS` | `Мои команды~ 🌿\n/list — твоя корзинка\n/info — обо мне` | Подпись в конце почти всех ответов |
| `MSG_LIST_HEADER` | `🍄 Твоя корзинка` | Заголовок списка ссылок |
| `MSG_LIST_EMPTY` | `Корзинка пустая~ 🧺\nОтправь мне ссылочку!\n\n{MSG_COMMANDS}` | Пустой `/list` |
| `MSG_LINK_SAVED` | `Положила в корзинку~ 🍄✨\n\n{MSG_COMMANDS}` | Ссылка сохранена |
| `MSG_LINK_DELETED` | `Убрала из корзинки~ 🍂\n\n{MSG_COMMANDS}` | Ссылка удалена (сейчас не используется в poll.js) |
| `MSG_LINK_NOT_FOUND` | `Не нашла эту ссылочку в корзинке… 🔍\n\n{MSG_COMMANDS}` | Ссылка не найдена по ID |
| `MSG_UNVERIFIED` | `Подожди немножко~ 🍄 Тебя скоро добавят в грибницу!` | Неверифицированный пользователь |
| `MSG_LINK_LIMIT` | `Ой, корзинка полная~ 🧺 Уже 10 товаров! Убери лишние через /list` | Лимит 10 ссылок |
| `MSG_INFO` | Представление Мико-Мико, поддерживаемые маркетплейсы, совет про автоудаление | Команда `/info` |
| `MSG_CB_DELETED` | `Убрала~ 🍂` | Callback popup при удалении |
| `MSG_CB_NOT_FOUND` | `Не нашла… 🍄` | Callback popup: ссылка не найдена |

## Функции

### `msgList(links: Array<{ id: string; name?: string }>): ListResult`

Формирует inline-клавиатуру для `/list`:
- Пустой массив → `{ text: MSG_LIST_EMPTY }`
- С элементами → `{ text: "🍄 Твоя корзинка (N)\n\n{MSG_COMMANDS}", reply_markup: { inline_keyboard } }`
- Каждая строка клавиатуры: `[displayName(name)]` `[🗑]` с callback_data `view:<id>` и `del:<id>`

### `displayName(name?: string): string` (внутренняя)

- `undefined` → `"Неизвестный товар"`
- Длина > 40 → обрезка до 39 + `…`
- Иначе → как есть

### Тип `ListResult`

```ts
interface ListResult {
  text: string;
  reply_markup?: {
    inline_keyboard: Array<Array<{ text: string; callback_data: string }>>;
  };
}
```

## Стиль для новых сообщений

- Тильда~ в конце фраз для мягкости
- Эмоджи: 🍄 🌿 🧺 🍂 🌸 ✨ 🍃 🔍 🛒 💡 ⚠️
- Грибная метафора: корзинка (список), грибница (сообщество), положила/убрала (CRUD)
- `MSG_COMMANDS` в конце большинства ответов (кроме unverified и callback popups)
- Без технических терминов, без канцелярита
